# ReleaseWeave release identity

The first ReleaseWeave release replaces the ChangeForge anvil/hammer identity with interlaced release strands. Canonical assets are docs/img/releaseweave-icon.png and docs/img/releaseweave-banner.png. The original logo.png, banner.png and full_logo.png paths also serve the refreshed assets for existing links.

Created with the built-in image_gen tool. The icon uses a transparent background; the banner uses ink navy with warm ivory, turquoise and amber. The outputs were inspected for composition and exact brand/tagline text. These are raster assets; no old artwork was used as an identity reference.

## Icon prompt

Use case: logo-brand. Asset type: final square app icon for the open-source Rust release-management CLI ReleaseWeave. A new geometric W formed by two interlaced flat ribbon strands, turquoise/teal and warm ivory, with a small amber stitch at one crossover. Meaning: independent release streams woven into one coherent path. Precise broad geometry, readable at small sizes, centered with padding, genuinely transparent background. No anvil, hammer, text, border, mockup or watermark.

## Banner prompt

Use case: logo-brand. Asset type: final wide GitHub README banner, approximately 3:1. Use the generated icon as an identity reference, preserving the woven W symbol and turquoise/ivory/amber palette. Dark ink-navy background, clean editorial design, generous padding. Large exact wordmark: ReleaseWeave. Smaller exact copy: Releases for single repos & monorepos. At the right, three restrained release strands converge into one amber node. No old ChangeForge symbol, extra copy, mockup framing or neon effects.
