# ReleaseWeave v0.2.0

The first release under the **ReleaseWeave** name: a Rust CLI for changeset-driven releases in single repositories and independently versioned monorepos. Historical ChangeForge releases remain available.

## Install

**Linux/macOS:** download `install.sh` from this release and run `sh install.sh --version v0.2.0`. It installs the matching native CLI into `~/.local/bin` after SHA256 and version checks.

**Windows x64:** download the ZIP or `install.ps1`; the PowerShell installer supports `-Version v0.2.0 -Prefix PATH`. Add its bin directory to your user PATH.

**Cargo, pinned source:**

```sh
cargo install --git https://github.com/ricardoleal20/ReleaseWeave.git --tag v0.2.0 --locked --bin releaseweave
```

All five native archives contain the CLI, MIT license, quickstart and complete single-repo/monorepo examples. `SHA256SUMS` covers the published distribution files.

## Single repository

```sh
releaseweave init --yes --mode single
releaseweave create --bump minor --message "Add configurable greetings"
releaseweave plan
releaseweave bump --dry-run
releaseweave bump
```

A 1.2.3 package becomes 1.3.0 with a changelog and proposed v1.3.0 tag.

## Monorepo

```sh
releaseweave init --yes --mode monorepo
releaseweave create --package acme-api --bump minor --message "Add health endpoint"
releaseweave create --package @acme/web --bump patch --message "Fix status indicator"
releaseweave plan --json
releaseweave bump
```

The bundled API moves from 1.4.0 to 1.5.0 and the web package from 2.1.0 to 2.1.1. The worker stays at 0.7.2. Only affected packages receive changelogs and independent proposed tags.

## Included

- Cargo.toml, package.json and pyproject.toml version editing; TOML comments and unrelated dependencies preserved.
- Interactive/noninteractive create, plan/list/status, dry-run, bump/version and JSON release metadata.
- Highest requested SemVer level applied once per package; safe empty plans and explicit errors for malformed changesets.
- Local Cargo.lock updates, path-dependency compatibility checks, operation locks and rollback on ordinary write/cleanup failures.
- GitHub release-PR/release-on-merge workflows; the CLI action is available as `ricardoleal20/ReleaseWeave@v0.2.0`.
- A new woven-strand icon and banner, current documentation, contribution policies and cross-platform CI.

## Scope

This is a pre-1.0 release supporting explicit stable versions and independent package releases. Automatic dependency propagation, Cargo version.workspace inheritance, prereleases, fixed-version groups and package-registry publishing are not implemented. Other package-manager lockfiles should be regenerated with their own tools. Legacy single-package ChangeForge config/changesets and the source-installable changeforge executable remain available; experimental AI/autocommit features are outside this contract.

Native Linux builds use the Ubuntu 22.04 baseline. The native macOS/Windows executables are not notarized/Authenticode-signed; tagged Cargo source is also available. Documentation and examples explain the exact supported behavior.
